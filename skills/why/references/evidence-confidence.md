# Evidence confidence

Explicit rationale is what an author or accepted decision actually says, with a citation. Supported rationale is a conclusion from several named sources; mark it as derived. Inference is your reading of incomplete evidence; explain the chain. A hypothesis is a possibility with insufficient support. Unknown means a bounded search did not find the reason.

Do not retrofit today's sensible explanation onto historical intent. An absent comment is not proof that a concern did not exist. A defensive branch can reflect an old incident, a mistaken assumption, or copied code; investigate rather than endorsing the user's guess.

When sources conflict, cite both and separate what each establishes. Read supersession links and scope in ADRs. A recent cleanup commit need not contain the original decision. State only material gaps and do not manufacture uncertainty after an explicit record answers the question.
